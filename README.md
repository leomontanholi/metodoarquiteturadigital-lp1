# Método Arquitetura Digital — página de vendas

## Arquivo da página

- `index.html`: página completa, com o CSS e o JavaScript incorporados no próprio arquivo.
- `assets/`: pasta com a foto usada na abertura da página.

Envie o arquivo `index.html` e a pasta `assets` sem alterar os nomes nem a organização. As fontes são carregadas pelo Google Fonts e o formulário da lista de espera envia os dados para o endereço configurado no código.

## Como publicar manualmente no GitHub Pages

1. Crie um repositório no GitHub.
2. Envie o arquivo `index.html` e a pasta `assets` para a raiz do repositório.
3. No repositório, abra **Settings → Pages**.
4. Em **Build and deployment**, escolha **Deploy from a branch**.
5. Selecione a branch `main`, a pasta `/ (root)` e clique em **Save**.
6. Aguarde o GitHub informar o endereço público da página.

O arquivo `README.md` é apenas este guia e não precisa ser publicado para a página funcionar.
